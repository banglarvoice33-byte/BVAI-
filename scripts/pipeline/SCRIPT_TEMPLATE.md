# BVAI Script Writer - 7 Rules (Classic News, Low Sound)

1. HOOK (0-3s): Main news in 1 sentence, with source.
   Wrong: "আজকের খবরে স্বাগতম..."
   Right: "গাজায় যুদ্ধবিরতির আলোচনা আবার শুরু হয়েছে।"

2. ONE SENTENCE = ONE FACT. Do not put 2 facts in 1 sentence.

3. NO CLAIM WITHOUT SOURCE. Wrong: "জানা গেছে..." Right: "আল জাজিরার প্রতিবেদন অনুযায়ী..."

4. NUMBERS CAREFULLY. If Article has no number, do not invent. Say "অনেকে", not "হাজার হাজার".

5. BANGLA CORRECT. যুক্তাক্ষর ঠিক, ড়/র, ং/ং গুলিয়ে ফেলো না. Use "জরুরি খবর", not "ব্রেকিং নিউজ".

6. TONE: Classic, low sound, slow. Pause 0.4s after sentence. Pause 0.2s before number/name.

7. END (last 5s): "সূত্র: ..." clearly. If uncertain, say "এখনো নিশ্চিত নয়".

Template:
HOOK (0-3s): [1 sentence]
BODY: [1 sentence = 1 fact + source] x 3-5
SCENE NOTE: [for each sentence: visual source, date, location]
END: [সূত্র: ...]
