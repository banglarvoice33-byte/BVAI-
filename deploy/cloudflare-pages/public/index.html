ডেপলয়মেন্ট নির্দেশিকা ও ফলব্যাক পেজ

এটি পূর্ণ সংবাদ অ্যাপ নয়। Next.js SSR, API, login, admin এবং automation চালাতে আলাদা Next.js backend প্রয়োজন। মূল অ্যাপের কোড ও ফিচার অপরিবর্তিতভাবে মূল frontend ফোল্ডারে আছে।

সঠিক পথ

ব্যক্তিগত non-commercial ব্যবহারে Vercel; অন্যথায় নিজের সার্ভারে Docker + Cloudflare DNS/Tunnel, অথবা পরীক্ষিত Workers adapter ব্যবহার করুন। Pages-এ এই ফলব্যাক পেজ আলাদাভাবে deploy করা যায়।
